# 🚀 Meu Site em HTML & CSS

Este é um projeto de site desenvolvido utilizando apenas **HTML5** e **CSS3**, com foco em aprendizado, organização de código e criação de interfaces modernas e responsivas.

## 📌 Sobre o projeto

O objetivo deste projeto foi praticar conceitos fundamentais do desenvolvimento web, como:

- Estruturação semântica com HTML
- Estilização com CSS
- Responsividade
- Organização de arquivos
- Boas práticas no front-end

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🎨 Funcionalidades

- Layout moderno
- Interface limpa e organizada
- Estrutura simples e eficiente
